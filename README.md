# Organizador de Ficheiros

## Objetivo
O **Organizador de Ficheiros** é uma aplicação desenvolvida em Python no âmbito da Atividade Prática Integradora da **UFCD 10806: Linguagens de Scripting e Linha de Comandos**. O programa tem como objetivo explorar o sistema de ficheiros local, identificando os ficheiros presentes na diretoria atual, as respetivas extensões (com destaque para `.py`, `.txt` e `.csv`), o número total de itens e o tamanho individual de cada ficheiro em bytes.

---

## Ferramentas utilizadas
* **Linguagem:** Python
* **IDE:** Visual Studio
* **Controlo de Versões:** GitHub
* **Editor de Texto:** Vim
* **Consola:** Git Bash

---

## Instruções de Execução

1 - Abra o **Git Bash** e execute o seguinte comando para clonar o projeto:
```bash
git clone https://github.com/leandrobbj/OrganizadorFicheiros.git
```

2 - Mova o script para a pasta alvo:
```bash
mv organizador.py /caminho/para/pasta-alvo/
```

3 - Entre na pasta alvo:
```bash
cd /caminho/para/pasta-alvo/
```

3 - Execute o Programa:
```bash
python organizador.py
```
